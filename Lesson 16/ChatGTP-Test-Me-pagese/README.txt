GLOBAL WARMING WEBSITE
======================

Pages:
- index.html   (homepage)
- gallery.html
- about.html
- contact.html

How to open:
1. Extract the ZIP folder.
2. Open index.html in a web browser.
3. Keep the HTML files, style.css and images folder together.

Technology:
- HTML5
- One shared CSS file
- Flexbox
- Image gallery
- Table
- Contact form
- Responsive media query
- No JavaScript or external framework

Note:
The contact form is visual only. A backend would be required to send messages.
All illustrations in the images folder were created specifically for this educational project.
